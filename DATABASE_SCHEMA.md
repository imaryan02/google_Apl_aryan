## AI Stadium Command Center

---

## 1. Database Goal

The database stores all operational data required for:

- stadium zones
- crowd monitoring
- smart routes
- VIP movement
- emergency alerts
- AI recommendations
- operator actions
- audit logs

The schema should support real-time operations, scalability, and traceability.

---

## 2. Recommended Database

Use:

- PostgreSQL  
or
- Supabase PostgreSQL

# 4. Tables

---

## 4.1 stadiums

Stores stadium-level information.

```sql
CREATE TABLE stadiums (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  location TEXT,
  total_capacity INTEGER,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

---

## 4.2 zones

Stores 8 stadium zones and their thresholds.

```sql
CREATE TABLE zones (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  stadium_id UUID REFERENCES stadiums(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  code TEXT NOT NULL,
  capacity INTEGER NOT NULL,
  warning_threshold NUMERIC DEFAULT 70,
  critical_threshold NUMERIC DEFAULT 85,
  current_density NUMERIC DEFAULT 0,
  movement_speed TEXT DEFAULT 'normal',
  risk_level TEXT DEFAULT 'safe',
  created_at TIMESTAMPTZ DEFAULT now()
);
```

---

## 4.3 cameras

Stores camera mapping with zones.

```sql
CREATE TABLE cameras (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  stadium_id UUID REFERENCES stadiums(id) ON DELETE CASCADE,
  zone_id UUID REFERENCES zones(id) ON DELETE SET NULL,
  name TEXT NOT NULL,
  stream_url TEXT,
  camera_type TEXT DEFAULT 'cctv',
  status TEXT DEFAULT 'active',
  created_at TIMESTAMPTZ DEFAULT now()
);
```

---

## 4.4 security_teams

Stores security/response teams.

```sql
CREATE TABLE security_teams (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  stadium_id UUID REFERENCES stadiums(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  team_type TEXT,
  contact_number TEXT,
  current_location TEXT,
  status TEXT DEFAULT 'available',
  created_at TIMESTAMPTZ DEFAULT now()
);
```

---

## 4.5 routes

Stores all public, VIP, staff, and emergency routes.

```sql
CREATE TABLE routes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  stadium_id UUID REFERENCES stadiums(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  from_zone_id UUID REFERENCES zones(id),
  to_location TEXT NOT NULL,
  route_type TEXT NOT NULL,
  capacity INTEGER,
  status TEXT DEFAULT 'open',
  priority INTEGER DEFAULT 1,
  assigned_team_id UUID REFERENCES security_teams(id),
  is_emergency_lane BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

Allowed route types:

```txt
public
vip
staff
emergency
```

Allowed status:

```txt
open
restricted
blocked
reserved
```

---

## 4.6 vip_movements

Stores VIP movement planning.

```sql
CREATE TABLE vip_movements (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  stadium_id UUID REFERENCES stadiums(id) ON DELETE CASCADE,
  vip_name TEXT NOT NULL,
  arrival_time TIMESTAMPTZ NOT NULL,
  entry_gate TEXT,
  destination TEXT,
  security_level TEXT,
  expected_people INTEGER DEFAULT 1,
  convoy_size INTEGER DEFAULT 1,
  primary_route_id UUID REFERENCES routes(id),
  backup_route_id UUID REFERENCES routes(id),
  assigned_team_id UUID REFERENCES security_teams(id),
  movement_status TEXT DEFAULT 'planned',
  created_at TIMESTAMPTZ DEFAULT now()
);
```

Allowed movement status:

```txt
planned
active
completed
cancelled
delayed
```

---

## 4.7 alerts

Stores all alerts generated by system or AI.

```sql
CREATE TABLE alerts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  stadium_id UUID REFERENCES stadiums(id) ON DELETE CASCADE,
  zone_id UUID REFERENCES zones(id),
  alert_type TEXT NOT NULL,
  severity TEXT NOT NULL,
  title TEXT NOT NULL,
  description TEXT,
  status TEXT DEFAULT 'active',
  source TEXT DEFAULT 'system',
  created_at TIMESTAMPTZ DEFAULT now(),
  resolved_at TIMESTAMPTZ
);
```

Allowed alert types:

```txt
congestion
stampede_risk
vip_conflict
route_blockage
emergency_incident
camera_failure
```

Allowed severity:

```txt
low
medium
high
critical
```

---

## 4.8 incidents

Stores emergency incidents and response lifecycle.

```sql
CREATE TABLE incidents (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  stadium_id UUID REFERENCES stadiums(id) ON DELETE CASCADE,
  alert_id UUID REFERENCES alerts(id),
  zone_id UUID REFERENCES zones(id),
  incident_type TEXT NOT NULL,
  severity TEXT NOT NULL,
  assigned_team_id UUID REFERENCES security_teams(id),
  status TEXT DEFAULT 'open',
  response_notes TEXT,
  started_at TIMESTAMPTZ DEFAULT now(),
  resolved_at TIMESTAMPTZ
);
```

---

## 4.9 agent_recommendations

Stores AI-generated suggestions.

```sql
CREATE TABLE agent_recommendations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  stadium_id UUID REFERENCES stadiums(id) ON DELETE CASCADE,
  alert_id UUID REFERENCES alerts(id),
  agent_type TEXT NOT NULL,
  recommendation TEXT NOT NULL,
  reasoning TEXT,
  suggested_action JSONB,
  status TEXT DEFAULT 'pending',
  reviewed_by TEXT,
  created_at TIMESTAMPTZ DEFAULT now(),
  reviewed_at TIMESTAMPTZ
);
```

Allowed status:

```txt
pending
approved
rejected
modified
executed
```

---

## 4.10 audit_logs

Stores every important operator/system action.

```sql
CREATE TABLE audit_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  stadium_id UUID REFERENCES stadiums(id) ON DELETE CASCADE,
  actor_type TEXT NOT NULL,
  actor_name TEXT,
  action TEXT NOT NULL,
  entity_type TEXT,
  entity_id UUID,
  metadata JSONB,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

Actor types:

```txt
operator
system
ai_agent
security_team
```

# 8. Important Design Rules

* Every table should have `stadium_id`.
* Every important action should be logged.
* AI recommendations should not directly modify critical state.
* Operator approval should be stored.
* Routes should be reusable.
* VIP movement should reference routes.
* Alerts should be linked to zones.
* Incidents should be linked to alerts.

---

# 9. Final Database Goal

The database should act as the operational memory of the stadium command center, supporting live monitoring, routing, VIP planning, emergency response, AI recommendations, and audit traceability.
